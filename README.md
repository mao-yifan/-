# 我在人间修行
异乡青年的生活笔记

二十多岁，我开始走进真正的生活。

离开熟悉的地方，遇见不同的人，为一些选择彻夜难眠，也曾因为一个尚且遥远的念头，觉得明天值得期待。那时的我有很多力气，也有很多迷茫：急着证明自己，又不知道究竟想成为什么样的人；渴望有人理解，又常常连自己的心事都说不清。

于是，我开始写。

写那些让我热泪盈眶的相遇，也写让我沉默很久的离别；写异乡的灯火、深夜的归途，写理想碰到现实之后，我怎样犹豫，怎样不甘，又怎样重新出发。有些事情发生时，我以为很快就会忘记。直到落笔，才发现它们一直留在心里，悄悄改变着我。

这些文章里，有我见过的人生百态，也有我始终没有回答好的问题：我究竟在追求什么？什么值得坚持，什么可以放下？如果生活没有按照期待展开，我还愿不愿意认真地过下去？

每一段经历，都把我带回这些叩问面前。有时我觉得自己已经想明白了，过不了多久，又会在另一场相遇、另一个深夜里动摇。

我把这些文字收在一起，是想留住那个仍会迷路、仍有激情、仍然怀抱希望的自己。许多年后，当我重新翻开它们，还能记起：我曾这样年轻，笨拙而用力地爱过，也曾在无人知晓的日子里，一次次把自己扶起来。

《我在人间修行》，写的是我走过的二十多岁。书页翻到这里，生活还在继续。

我仍有许多不懂，也仍想去看看。
